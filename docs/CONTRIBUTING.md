# Contributing to XAUUSD Trading Bot

Thank you for your interest in contributing to this project!

The XAUUSD Trading Bot is an open-source project under active development. Contributions, suggestions, bug reports and improvements are welcome.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your improvements.
4. Test your changes.
5. Submit a pull request with a clear description.

## Areas Where Contributions Are Welcome

- Technical analysis and indicators.
- Historical market data integration.
- Backtesting algorithms.
- Trading strategy development.
- Risk management.
- Performance optimisation.
- Documentation and testing.

## Code Guidelines

- Write clean, readable and maintainable Python code.
- Use meaningful variable and function names.
- Include comments where necessary.
- Add tests for new functionality.
- Document new features and changes.

## Reporting Issues

Please provide:

- A clear description of the issue.
- Steps to reproduce it.
- Expected behaviour.
- Actual behaviour.
- Relevant error messages, if applicable.

## Development Philosophy

This project prioritises transparency, modularity, reproducible testing and responsible algorithmic trading research.

All contributions should help make the project more reliable, accessible and useful to the open-source community.

Thank you for helping improve this project!
